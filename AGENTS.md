# Pixelbot contributor guide

Pixelbot 3.0 is an app-first Pixeltable 0.7.7 project. Python 3.11+ and Node 22.12+ are required.

## Architecture

- `backend/pixelbot/app.py`: application entry, custom FastAPI app, and module-scope `FastAPIRouter` routes.
- `backend/pixelbot/schema.py`: the single `TableModel` schema for `pixelbot_v3`.
- `backend/pixelbot/routers/`: custom REST routes. The database router is read-only.
- `backend/pixelbot/static/`: production SPA package data generated by Vite.
- `frontend/`: React SPA with route-level lazy loading.
- `.agents/skills/pixeltable-skill/`: bundled current Pixeltable guidance.

## Catalog rules

Use a fresh `PIXELTABLE_HOME=backend/.pixeltable-v3`. Apply only to `pixelbot_v3`. Never inspect, mutate, copy, drop, or migrate the old `agents` catalog. CSV imports live under `pixelbot_scratch`, are registered in `pixelbot_v3.csv_registry`, and are resolved from client-facing registry UUIDs.

Declare stored columns with annotations and computed columns with assignments in `schema.py`. Keep `has_default_idxs=False`; add targeted B-tree and embedding indexes through `__indexes__`. Do not mutate the catalog during import or server startup. Do not add runtime expression evaluation, dynamic computed columns, arbitrary catalog paths, or database mutation endpoints.

A changed computed expression is unsupported by schema migration. Rename the column, or drop and re-add it in separate schema updates. `--allow-destructive` does not change that restriction.

## Workflow

```bash
cd backend
export PIXELTABLE_HOME="$PWD/.pixeltable-v3"
uv sync --locked --group dev
uv run --env-file .env pxt schema check pixelbot/app.py
uv run --env-file .env pxt schema diff pixelbot/app.py pixelbot_v3
uv run --env-file .env pxt schema update pixelbot/app.py pixelbot_v3 -f
uv run --env-file .env pxt service update pixelbot/app.py pixelbot_v3 app --port 8000 -f
```

Debug with `pxt service list`, `pxt service logs pixelbot_v3/app`, `pxt errors TABLE`, and `pxt recompute TABLE COLUMN --errors-only -f`. Errors-only recomputation takes exactly one column.

## Required checks

```bash
cd backend
uv run ruff format --check pixelbot tests
uv run ruff check pixelbot tests
uv run mypy pixelbot
uv run pytest
uv build

cd ../frontend
npm run lint
npm run build
```

Tests must set a temporary `PIXELTABLE_HOME` before importing Pixeltable. Provider mocks validate wiring only. Do not make paid provider calls, deploy hosted services, or touch the Pixeltable repository from tests.
